# Original dataset

This directory is the local input location for the MS COCO 2017 dataset used
by the pipeline:

- `train2017/`
- `val2017/`
- `annotations/`

The directory is intentionally ignored by Git because the source images,
annotations, and archive files are large and remain available from the
official dataset source. Place the extracted files here before running the
pipeline. Do not commit dataset contents or credentials.
